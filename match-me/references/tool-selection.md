# 工具选择参考

按能力选择工具，不按品牌堆砌。具体可用性以当前环境和用户授权为准。

| 需求 | 优先能力 | 常见候选 | 选择要点 |
|---|---|---|---|
| 文档/知识整理 | 文档读取、搜索、引用、Markdown 输出 | `rg`、本地脚本、documents skill | 先本地处理；保留来源和段落定位 |
| 表格汇总 | `.xlsx`/`.csv` 读写、公式和格式校验 | spreadsheets skill、Python、LibreOffice CLI | 保护原文件，先写副本并检查公式/数字 |
| 汇报材料 | PPTX 生成、模板复用、渲染检查 | presentations skill、PptxGenJS 或现有 CLI | 先提纲和数据核对，再生成可编辑草稿 |
| 行业信息 | RSS/API/浏览器检索、去重、引用 | 浏览器工具、用户指定 API、research skill | 限定来源和时间窗，不把摘要当原文 |
| 定时准备 | 任务调度 | Codex heartbeat、系统任务、CI | 明确时区、输入范围、停止方式和通知策略 |
| 应用内交付 | 目标 APP 的连接器/MCP | 仅使用已配置 connector | 外发前确认收件人、内容和附件 |
| 偏好建模 | 可编辑配置文件或本地 JSON | 项目内 `preferences.json`、用户指定存储 | 记录来源和置信度，支持删除和覆盖 |

## 决策顺序

1. 能用本地已有能力解决，就不新增外部依赖。
2. 需要联网时，优先用户指定的来源和已配置连接器。
3. 需要安装时，说明维护状态、权限、成本、数据去向和卸载方式。
4. 对不可逆或外发动作，先生成预览，再请求明确授权。
